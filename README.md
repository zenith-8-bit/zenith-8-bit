## About Me

I’m a Computer Science student who loves building things that sit at the intersection of systems, automation, AI, and real-world problem solving. My work is a mix of polished product ideas, low-level experimentation, and projects inspired by curiosity: from Android automation and browser extensions to language technology and robotics.

I enjoy turning abstract ideas into working prototypes quickly — especially when they involve making computers do something useful, clever, or unexpectedly powerful.

I’m especially interested in:

- AI-powered automation
- Android / device scripting + accessibility tooling
- Real-time systems and networking
- Robotics and embedded experimentation
- Language technology for underrepresented languages
- Building useful tools that people can actually use

## Featured Projects

### 1) MixVault 🎵
A Chrome extension that turns YouTube / YouTube Music mixes into reusable music collections.

- Converts long streaming mixes into structured playlists
- Built with browser extension APIs + content extraction logic
- Focused on reusability and personalization

Tech: JavaScript, Chrome Extension APIs

Repository: https://github.com/zenith-8-bit/MixVault

---

### 2) Cursor for Phone 📱
A local Android automation agent inspired by AI computer-use tools, but designed to run from Termux.

- Reads UI hierarchy from Android
- Performs taps, typing, and interactions via ADB / device automation
- Works on-device without requiring a desktop machine

This project blends AI, automation, mobile systems, and practical tool design.

Tech: Python, ADB, Android, Termux

Repository: https://github.com/zenith-8-bit/Cursor-For-Phone

---

### 3) Meitei Mayek Transliteration Tool ✍️
A script and tool for transliterating Romanized Manipuri text into Meitei Mayek script.

- Helps preserve a native script in digital workflows
- Attention to linguistic accuracy and usability
- An example of my interest in language technologies for under-resourced communities

Tech: WebAssembly, JavaScript, Python

Repository: https://github.com/zenith-8-bit/meitei-mayek-transliteration

---

### 4) Multi-User Live Test Toolkit 🧪
A real-time examination system built for live MCQ and numerical tests with synchronized sessions.

- Live leaderboard
- Admin dashboard
- Real-time multi-user experience
- Built around Express + Socket.io + SvelteKit

This project reflects my interest in interactive systems and full-stack engineering.

Tech: Express.js, Socket.io, SvelteKit, JavaScript

Repository: https://github.com/zenith-8-bit/multi-user-live-test-toolkit

---

### 5) MemoryBank 🧠
A mobile app concept designed as a “second brain” for individuals with short-term memory challenges.

- Stores important reminders and memory cues
- Focuses on usability and practical support
- Shows my interest in human-centered software

Tech: Dart, Flutter-like app development

Repository: https://github.com/zenith-8-bit/MemoryBank

---

### 6) Device Audio Sharing / SoundCloud-style Experiment 🔊
A small web application for live multi-device audio sharing using peer-to-peer communication.

- Real-time voice streaming between devices
- Browser-based setup
- Explores WebRTC and low-latency media communication

Tech: JavaScript, Firebase, WebRTC

Repository: https://github.com/zenith-8-bit/soundcloud

---

### 7) ADB Notification Data Parser 📲
A Python utility that extracts structured data from Android notification dumps.

- Parses notification text, titles, actions, timestamps, channels, and metadata
- Useful for automation and monitoring workflows on Android

Tech: Python, ADB

Repository: https://github.com/zenith-8-bit/adb-notification-data-parser
